# Contributing

Weavewing is a fork of [T3 Code](https://github.com/pingdotgg/t3code). This repository has its own
maintainers, so report Weavewing problems here rather than upstream.

## Report a bug

Open an issue in the **Issues** tab of this repository on GitHub.
Say which version you run, what you did, what you expected, and what happened instead. Search the
open issues first, and add what you saw to an existing one instead of opening a duplicate.

Report security vulnerabilities privately, as [SECURITY.md](.github/SECURITY.md) describes, not in a
public issue.

## Pull requests

- Fix one problem per pull request. Include every change that fix needs across contracts, server,
  clients, tests, and docs.
- Say how you found the problem, how you checked the fix, and what you saw. "Tests pass" is not
  evidence.
- UI changes need before and after screenshots. Upload them to the pull request; do not commit them.
